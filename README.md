# Halftone Arrange for Adobe Illustrator

選択したオブジェクト(スキャンした筆跡のベクターなど)を、カラーハーフトーン(網点)のようにグリッド配置する Illustrator スクリプトです。

by nyakko

## 特長
- **並べ方**: グラデーション(線形/円形に大→小、反転可)、またはランダム。
- **複製**: 1個だけ選ぶか「複製して並べる」をオンにすると、指定の個数まで複製。90°単位の回転・左右反転で、1つの元から8通りの形を作れます。元は残します。
- **配置の形**: 正方形 / 横長 / 縦長 / 円 / 列数で指定。
- **グリッド**: ピッチ(自動または mm 指定)、千鳥配置、スクリーン角度(Y 0° / C 15° / K 45° / M 75°)。
- **サイズ**: 位置でサイズを付け直す自動拡大縮小。重ならないよう制限も可能。
- **ばらつき**: 位置の揺らぎ、回転のばらつき。シード固定で再抽選できます。
- プレビュー対応。前回の設定を記憶します。
- 色は扱いません(ハーフトーンの配置だけを行います)。

## 使い方
1. `halftone_arrange.jsx` を、Illustrator の Scripts フォルダに置きます。
   - Windows の例: `C:\Program Files\Adobe\Adobe Illustrator <バージョン>\Presets\ja_JP\スクリプト\`
   - もしくは、Illustrator の「ファイル > スクリプト > その他のスクリプト」から直接選んで実行できます。
2. 配置したいオブジェクトを選択します。
3. 「ファイル > スクリプト > halftone_arrange」を実行し、設定パネルで調整します。

## 動作環境
- Adobe Illustrator(バージョンごとの動作確認は、まだ十分ではありません。作者の環境は、最新版の Windows です)。

## 設定の保存先
前回の設定は、ユーザーデータフォルダの `halftone_arrange_settings.txt` に保存されます。
